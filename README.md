# 1×1 Lernkarten

Eine einfache Lernkarten-App zum Üben des kleinen Einmaleins.

**▶ Jetzt üben:** https://christofheiss.github.io/einmaleins-lernkarten/

## So funktioniert's

- **Rechnung → Ergebnis:** Vorne steht die Aufgabe (z. B. `6 × 7`), antippen zeigt das Ergebnis.
- **Ergebnis → Rechnungen:** Vorne steht ein Ergebnis (z. B. `24`), auf der Rückseite stehen alle 1×1-Rechnungen, die dazu passen.
- Mit **✓ Gewusst** / **✗ Nicht gewusst** bewertest du dich selbst. Die Ergebnisse werden im Browser gespeichert.
- Karten, die du oft nicht gewusst hast, kommen häufiger dran.
- Unter **Ergebnisse** siehst du eine farbige 1×1-Tabelle mit deinem Lernstand.
